## Краткий пересказ семинара:

### Основная идея

Доклад посвящен **BOLDSEA** – системе исполняемых спецификаций, разработанной для интеграции с большими языковыми моделями (LLM). Система использует язык **BSL** для описания событий, атрибутов и отношений, формируя исполняемый граф. Цель BOLDSEA – обеспечить формальную, верифицируемую и однозначную основу для работы с LLM, создавая симбиоз человеческого понимания и машинной точности.

### Ключевые тезисы

*   **LLM как языковые процессоры:** LLM могут переводить между формальными и неформальными языками, включая генерацию кода.
*   **Проблемы LLM:** Верификация и временной лаг при работе с кодом затрудняют постоянное обновление функционала.
*   **Исполняемые спецификации:** BOLDSEA предлагает исполняемые спецификации, где описание (спецификация) исполняется специальным движком.
*   **BSL:** Язык BSL используется для описания событий, их условий, атрибутов и отношений, формируя предметный и причинный графы.
*   **Интеграция с LLM:** Движок BOLDSEA может взаимодействовать с LLM, позволяя им читать и писать в граф спецификаций, управляя приложениями.
*   **Аудит и права доступа:** Система обеспечивает полный аудит действий через событийный граф и имеет гибкую систему прав доступа.

### Детали и аргументы

*   **Структура BSL:** Каждая запись в BSL – это событие (акт, приписывание атрибута, отношение) с условиями выполнения. Движок исполняет выполнимые события.
*   **Формат события BSL:** Включает идентификатор, ссылку на базовое событие, тип, значение, модель, актора, дату и причинную ссылку, позволяя строить предметные и причинные графы.
*   **Интеграция с Claude:** Показана интеграция Claude с движком BOLDSEA, позволяющая LLM создавать приложения, читая и записывая в граф спецификаций.
*   **Примеры приложений:** Созданы приложения для службы поддержки и Kanban-доски.
*   **Верификация кода:** BOLDSEA генерирует "стопроцентно валидный код семантических моделей".
*   **Аудит действий:** Полный аудит всех действий записывается в граф как последовательность событий.
*   **Агенты и управление:** Система использует агентов (LLM, BSL, скриптовые) для выполнения задач. Common bar – адаптивный интерфейс управления.
*   **Права доступа:** Назначаются на модели, контролируя изменения и создание новых агентов/данных.
*   **Интернационализация (I18N):** Реализована на уровне View-моделей.

### Выводы

*   BOLDSEA – мощный инструмент для создания исполняемых спецификаций, обеспечивающий формальную основу для систем с LLM.
*   Система позволяет создавать верифицируемые приложения с полным аудитом действий, используя декларативный язык BSL.
*   Интеграция с LLM открывает новые возможности для автоматизации разработки и управления сложными системами.
*   Гибкая система прав доступа и возможность расширения функционала делают BOLDSEA перспективной платформой для бизнес-приложений.
